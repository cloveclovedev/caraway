# cardamap の文書

cardamap は、自動運転と Physical AI の論文、ニュース記事、規格、安全論証の文書を集めて選び、主題ごとに互いの関係を整理して読めるようにするサイトである。

このページは、`docs/ja/` にあるすべての文書の入口である。

## 初めて読むとき

次の順に読むと、全体がつかめる。

1. [要求仕様書](requirements/overview.md): 何を解決したいか、どこまでやるか、どの順に作るか
2. [用語集](requirements/glossary.md): 文書の中の語の意味
3. カテゴリごとの要件: [収集](requirements/source/index.md)、[ふるい分け](requirements/screen/index.md)
4. [技術要素](requirements/technology.md): 何で作るか、なぜそれを選んだか
5. [ソースコード全体構成](architecture/overview.md): コードをどう分け、どうテストするか
