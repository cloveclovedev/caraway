# 用語集

この文書群で使う語の意味を決める。1つの語を1行に書く。「使わない言い方」は、同じものを指す別の言い方で、文書では使わない。

| 語 | 意味 | 使わない言い方 | 英語 |
|---|---|---|---|
| 編集者 | 候補の採否を決め、主題と関係を付け、解説を書く人。1人である | 管理者、キュレーター | editor |
| 読者 | caraway で整理した結果を読む人 | ユーザー、訪問者 | reader |
| 資料 | caraway の外にある1件の文書。種類は、論文、ニュース記事、規格、安全論証の文書である | 文献、アイテム、エントリー | document |
| 書誌情報 | 資料を見分けて出典を示すための情報。題、著者、公開日、識別子、出典へのリンク、要旨からなる | メタデータ | bibliographic record |
| 識別子 | 収集元や発行者が資料に付けた、変わらない名前。例えば arXiv の ID、DOI、規格の番号である | | identifier |
| 収集元 | 資料の書誌情報を配るサービスと、そこから何を取るかの条件の組。例えば「arXiv の、あるカテゴリの新着」である | フィード | source |
| 収集 | 収集元から書誌情報を取ってきて、候補として保存すること | クロール、スクレイピング | collection |
| 候補 | 収集したが、編集者がまだ採否を決めていない資料 | 未読、インボックス | candidate |
| 採否 | 候補を採用するか、見送るかの編集者の決定 | レビュー、承認 | decision |
| 採用 | 候補を、整理の対象にすると決めること。採用した資料だけが、一覧と主題のページに出る | | accept |
| 見送り | 候補を、整理の対象にしないと決めること。見送った資料は、同じものを再び候補にしないために残す | 却下、削除 | decline |
| 主題 | 資料をまとめる技術や安全の話題。例えば「End-to-End 運転」「最小リスク操作」である。主題は親子にできる | タグ、トピック | topic |
| 関係 | 2つの資料のあいだの、種類を持つ結び付き。例えば「この論文は、この規格の要求を扱う」である | エッジ | relation |
| 解説 | 編集者が主題について書く文章。その主題の資料と関係を踏まえて、何が分かっていて何が分かっていないかをまとめる | ノート、まとめ | commentary |
| 要約 | 1件の資料の中身を、編集者の言葉で短く書いたもの。資料の要旨の写しではない | サマリー | summary |
| 要旨 | 資料の著者が書いた、資料の短い説明 | アブストラクト、抄録 | abstract |
| 出典 | 資料の正本がある場所と、そこへのリンク | 引用元、参照元 | origin |
| 家のサーバー | 公開する前の caraway を動かす、編集者の家のコンピューター | ホスト | home server |
