# 要求と要件

cardamap の要求と要件の文書の入口である。

## 全体

- [要求仕様書](overview.md): 解決したい課題、目的、指標、登場人物、範囲外、フェーズ
- [技術要素](technology.md): 使う技術と、選んだ理由
- [用語集](glossary.md): 語の意味と、使わない言い方
- [バックログ](backlog.md): 今のバージョンには入れないが、あとで取り入れたいこと
- [ソースコード全体構成](../architecture/overview.md): パッケージと、その役割と設計

## カテゴリごとの要件

IDの接頭辞は `CDM` である。カテゴリごとにディレクトリを分け、要件のページ (`index.md`) と図を置く。

| カテゴリ | ページ | 内容 |
|---|---|---|
| `SOURCE` | [収集](source/index.md) | 収集元の決め方、収集の動かし方、保存するもの |
| `SCREEN` | [ふるい分け](screen/index.md) | 主題の定義、収集した資料への主題と評価の付け方、候補にするものと自動で見送るもの |

v0.1 では、次のカテゴリも足す見込みである。カテゴリは、最初の要件を書くときに足す。

| カテゴリの案 | 内容 |
|---|---|
| `CURATE` | 候補の採否、主題の直し方、要約 |
| `BROWSE` | 採用した資料の一覧、検索、主題のページ |
| `DEPLOY` | 家のサーバーへの配り方と動かし方、バックアップ、異常の知らせ方 |
